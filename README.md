# dsa_project

The program presents a sophisticated implementation of segment trees
 to manage a vector of pairs containing attack and health values, facilitating
 efficient range queries and data manipulation. Notably, it incorporates multiple
 segment trees, each optimized for specific functionalities, such as summing values
 and tracking the maximum and minimum indices for both attack and health.
 This allows for quick aggregation of metrics and precise data retrieval, which is
 invaluable for applications in resource management and performance analysis. This
 efficiency is essential for scenarios requiring frequent updates and queries, making
 the program highly scalable.
 This robust implementation includes dynamic update functionality, which means
 any changes to the attack or health values are promptly reflected across all rel
evant queries. This feature is particularly advantageous for real-time applications
 where immediate data consistency is crucial.
